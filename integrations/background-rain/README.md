# Background Live Show, desktop launchers and Buff trial links

MAKE IT RAIN previously waited for two browser paint callbacks before acknowledging presentation. A covered/background Live Show could suspend those callbacks and fail the 1.7-second presentation deadline. Live Show now acknowledges real, unmuted media playback without waiting for painting; OBS retains its two-frame check. Browser output receives a six-second connection budget. Nonce checks, output ownership, STOP and actual soundtrack-ended receipts remain required. The dedicated Edge profile disables background timer/renderer throttling.

The actual installed test ran with Live Show in the background and OBS closed. Audio reported playing at 403 ms and ended at 24,371 ms: 23.968 seconds of playback, with no writer call or output error. The host completed its seating/hide sequence afterward. This verifies background playback, not an explicitly minimized browser.

The desktop has STANK TANK, Live Show and OBS Reactive shortcuts to a small control window. It starts/stops the existing host, opens Buff's handoff folder, verifies/prepares a temporary Cloudflare link, and stops that link. Ordinary browser profiles and OBS scene collections are not modified.

The local producer panel adds **New Buff HTTPS link** and **Copy Buff link**. Renewal launches a fixed installed helper with no browser-supplied command or arguments. It verifies the new public endpoint before enabling copy, regenerates the four private handoff files, and updates the trusted HTTPS origin in the running host. A named mutex serializes concurrent launcher requests. The producer-only endpoints require the local Host and loopback connection, reject forwarding headers, require the operator credential, and require the exact local Origin for changes. Buff's remote operator and view-only keys cannot renew links. Existing audio mode and voice processes stay running during renewal.

The helper uses Cloudflare Quick Tunnels for a temporary trial. A fresh tunnel replaces the prior address; stopping sharing removes remote access. The bundled helper was downloaded from the official cloudflare/cloudflared release 2026.10.1, with SHA-256 `4d2490e74082c5d48dbfedaf92576fa5bd1702379ab88eb7faa0cfbe8dc891b6`. The executable, access keys, private settings, tunnel logs and handoff shortcuts are excluded from Git. Other installations must supply a verified `tools/cloudflared.exe` before using these scripts.

`installed.patch` applies to the exact newer installed source described by `manifest.json`, after the voice-dyad-lite integration. Do not apply it blindly to the older repository host. Before hashes identify the pre-rain sources; after hashes identify the actual deployed Windows bytes. Patch text is UTF-8/LF without BOM. Replay compares normalized source text. Local rollback copies retain originals and private settings outside this repository.

Validation: 309 repository Node tests, 340 staged Node tests, two additional panel interaction tests, seven final sharing tests, 27 earlier background/ownership tests, Python compilation and PowerShell syntax checks. The supplied tests in `tests/` belong in the staged installation's `test/` directory; they exercise its newer panel. The standalone helper and its unit tests also live in the repository source tree. Sanitized runtime receipts record full rain playback, HTTPS authorization and link renewal. Frozen GOLD files remain byte-identical.

HTTPS controls have been tested from this machine through the public edge. Buff's audio/video WebRTC connection still requires a first trial from his own network. Tailscale Funnel was unavailable because the tailnet administrator had not enabled it; no Tailscale policy was changed. The draft PR stays unmerged.
